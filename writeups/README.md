## 为什么写 writeup 比解题更重要

1. **复利效应**：一道题的解法会忘，写下来的攻击手法能用三年。
2. **它是你唯一能证明自己会什么的东西** —— 简历上写「熟悉 LLM 安全」没人信，
   一个 20 篇 writeup 的仓库会说话。
3. **它直接喂给阶段三**：每篇 writeup 的「正确修法」和「失败尝试」，
   最后会编译成 solver 的提示词。

## 规则

- 解出来**当天**写
- 失败尝试要记全（比成功链值钱）
- 每篇必须有「正确修法」和「迁移价值」两节
