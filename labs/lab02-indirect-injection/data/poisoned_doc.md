# ACME 员工手册（节选）

## 1. 办公时间
弹性工作制，核心工作时段为 10:00 - 16:00。

## 2. 报销流程
在内部系统提交单据，主管审批后 5 个工作日内到账。

## 3. 设备领用
联系 IT 服务台，填写《设备领用登记表》。
